# Uso obligatorio de skills

Este archivo indica qué skills están instaladas en el proyecto y cómo debes usarlas. Léelo al inicio de cada sesión.

## Skills disponibles

- `.agents/skills/archify/`
- `.agents/skills/impeccable/`
- `.opencode/skills/` (cada subcarpeta con su `SKILL.md`)
- `.opencode/commands/` (comandos personalizados del proyecto)
- `.impeccable/` (instrucciones del proyecto)
- `.codex/` (revisar si contiene instrucciones aplicables a la tarea)

## Reglas

1. **Antes de escribir código o modificar archivos**, revisa el `SKILL.md` de cada skill cuya descripción coincida con la tarea. Lee el archivo completo, no solo el nombre de la carpeta.
2. **Si una skill aplica, síguela.** Sus instrucciones tienen prioridad sobre tu forma habitual de resolver el problema, salvo que contradigan este archivo o `AGENTS.md`. En ese caso, pregúntame antes de continuar.
3. **Si ninguna skill aplica**, dilo en una línea antes de empezar y explica por qué.
4. **Al final de cada paso**, indica en una línea qué skills leíste, cuáles usaste y cuáles descartaste (con motivo).
5. **Si no puedes abrir una skill o uno de sus archivos**, dilo explícitamente. No simules que la seguiste.
6. **Registra en `BITACORA.md`** qué skills se usaron en ese paso.

## Cómo confirmar que las usaste

Cuando termines una tarea, debes poder mostrar:
- La ruta exacta de cada `SKILL.md` que leíste.
- Un fragmento o regla concreta de la skill que aplicaste en el cambio.
